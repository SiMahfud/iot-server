Panduan mudah menghubungkan mikrokontroler ke server

1. Buat Profil Perangkat di Server

Langkah A: Flash Firmware Universal

Tancapkan ESP ke USB laptop/PC. Buka menu Tab Tools > Web Flasher, pilih firmware universal, lalu klik Flash Firmware.

Langkah B: Sambungkan via WiFi Captive Portal
  1. Nyalakan ESP. Cari WiFi bernama AGY-SETUP dari HP / Laptop Anda.
  2. Kata sandi AP: admin1234.
  3. Pop-up login akan muncul otomatis (atau buka browser ketik: http://192.168.4.1).
  4. Masukkan Nama WiFi rumah, Password WiFi, Host Gateway, dan Device Key:
Host: IP Server ini | Port: 3050 | Device Key: wemos-secret-key-3377

Gunakan library AgyGatewayClient di PlatformIO atau Arduino IDE:

#include <Arduino.h>
#include <AgyGatewayClient.h>

AgyGatewayClient iot;

void setup() {
  Serial.begin(115200);
  iot.enableWatchdog(8);
  iot.enableStatusLed(LED_BUILTIN, true);
  iot.enableDynamicPins(true);
  
  // AutoConnect ke WiFi tersimpan atau buka Portal
  iot.autoConnect("AGY-SETUP", "admin1234", 60);
}

void loop() {
  iot.loop();
}
